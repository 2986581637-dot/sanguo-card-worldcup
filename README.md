# 三国武将卡牌世界杯

纯前端玩家模式版本，包含150张武将卡牌、完整世界杯赛制、三阶段战斗、玩家手动选将、电脑自动模拟和冠军页面。

## 打开方式

直接双击 `index.html`，或在 VS Code 中使用 Live Server 打开。项目不需要安装依赖，也不需要 Python、Node、数据库或网络连接。

## 文件说明

- `index.html`：首页、图鉴、世界杯抽签、赛事导航与弹窗结构
- `style.css`：古风卡牌、积分榜、赛程、战报、冠军页和响应式布局
- `characters.js`：150名人物数据；只保留武力与智力，综合 `power = max(martial, intelligence)`，并生成唯一排名与品阶
- `game.js`：抽签、三阶段单场比赛、小组积分排名、16强抽签、固定淘汰赛树与页面交互
- `playerMode.js`：玩家球队、隐藏电脑手牌、普通AI、逐回合确认选将、翻牌动画和赛事推进
- `audioManager.js`：单一背景音乐的循环播放、静音、音量和缺少文件时的安全降级
- `tournament_test.js`：自动模拟5届完整世界杯的数据验证脚本
- `player_mode_test.js`：自动验证5届玩家模式、轮空、动画状态和淘汰后观战
- `privacy_ai_audio_test.js`：验证电脑暗牌、AI权重/随机性/不读牌和BGM控制
- `balance_test.js`：验证150人双属性综合战力、唯一排名和品阶区间；加 `--full` 输出完整排名表
- `portrait_test.js`：验证当前批次立绘路径、WebP文件、体积、缺图回退与头顶安全裁切
- `assets/audio/`：本地背景音乐目录；自行放入合法的 `bgm.mp3`
- `assets/portraits/`：原创角色立绘WebP；未配置立绘的人物继续显示古风剪影
- `PORTRAIT_SOURCES.md`：立绘生成方式、提示词要点与版权来源记录

## 完整赛事流程

1. 每届世界杯从150名武将中随机抽取128人，其余22人进入未抽中名单。
2. 128人再次随机排列，组成32支球队，每队严格4人，武将不会重复分配。
3. 32支球队再次随机排列，分入A—H八个小组，每组严格4队。
4. 每组进行6场单循环赛，每队3场；胜者得3分，败者得0分，共48场。
5. 每组前2名晋级，共16队；16队只在此时重新随机抽签一次。
6. 16强之后沿固定对阵树依次进行8强和半决赛，不再重新抽签。
7. 两支半决赛败队进行季军赛，两支胜队进行决赛，最终产生冠军、亚军、季军和第四名。
8. 冠军页面可开始新一届世界杯，全部抽签、积分、战报和淘汰赛状态都会重置。

小组排名依次比较：积分、所有同分球队之间的内部交手积分、累计净剩余综合战力、累计剩余综合战力，最后随机抽签。两队同分时内部交手积分就是直接胜负；三队同为6分时会建立三队内部小积分榜，若仍循环相克，再由净胜战力公平决出名次。球队不计算赛前总战力。

## 正式单场球队比赛规则

旧版“两阶段比赛机制”已经取消。小组赛、16强、8强、半决赛、季军赛和决赛统一使用 `simulateTeamMatch(teamA, teamB)` 三阶段比赛函数。每场比赛开始时，两队四名武将全部恢复；阵亡状态只在当前比赛内有效。

每队由四人中综合战力最高者担任队长，队名为“队长姓名+队”。同战力时按人物固定排名顺序选择，不随机。

### 第一阶段：四场跨队单挑

- 每队固定4名武将，比赛双方记为A队和B队。
- A队和B队分别独立决定本回合出场者并一一配对，共进行固定4场1v1；自动赛事也调用统一AI选将函数。
- 每场只能是A队武将对阵B队武将，绝对禁止任何同队内战。
- 每名武将在第一阶段恰好出战一次，不允许胜者继续挑战下一名对手。
- 单挑实际战力为 `原综合战力 × 属性克制系数`：谋略克强攻、强攻克防守、防守克谋略。克制为1.06，被克制为0.94，同类型为1.00。
- 实际战力较高者获胜并存活；如果双方实际战力完全相同，则双方同归于尽。
- 正常战力较低者有一次爆冷抽取：差距不超过5%为12%，5%到10%为8%，10%到20%为4%，超过20%为1%。触发后弱者最终战力为正常战力的1.15倍，仍按最终战力比较胜负。
- 随机只用于上述低概率爆冷，不再叠加其他随机战力修正，也不考虑特性或阵营。
- 因为同战力会同归于尽，四场结束后的幸存总数可能少于4人。

### 全灭判定

- 第一阶段结束后，如果只有A队幸存人数为0，B队立即获胜；反之A队获胜。
- 如果同归于尽导致双方同时全灭，以50%随机产生本场唯一胜者，保证赛事可以继续推进。
- 一方全灭时不进入第二阶段和第三阶段。

### 第二阶段：幸存者再次跨队单挑

- 只有双方都至少有1名幸存武将时才进入第二阶段。
- 第二阶段仍然只允许A队幸存武将对阵B队幸存武将。
- 单挑场数等于 `min(A队幸存人数, B队幸存人数)`。
- 双方分别独立选择相同数量的幸存武将并一一配对；每名武将在第二阶段最多出战一次。
- 人数较多一方没有被抽中的武将轮空，自动存活进入第三阶段。
- 每场仍调用统一属性克制和爆冷函数计算最终战力；最终战力相同则同归于尽。
- 第二阶段结束后，如果一方已经全灭，另一方立即获胜，不进入第三阶段。

### 最后一轮：单挑或合击

- 前两阶段结束后双方仍有幸存武将，最后一轮继续在普通战斗场景进行；一方全灭则直接结算。
- 双方各剩一人时复用普通单挑判定，包括属性克制与现有爆冷规则，不显示团队加总。
- 至少一方有多人时，全部最终幸存武将参战，比较各自 `effectivePower` 之和；全军振奋逐人加成，军心振奋按当前战术规则给己方最后一轮加 6。
- 多人战力相同则先比最高幸存武将的 `effectivePower`，仍相同则以 50% 随机决定胜负。
- 玩家比赛沿用普通战斗卡牌、VS、冲击和胜负动画；合击时在同一场景内展示加总过程，战斗结束后再显示比赛结果。

### 比赛记录

点击已完成比赛可以查看完整战报：第一阶段四场单挑及阶段后人数；第二阶段的出战武将、轮空武将、单挑结果及阶段后人数；最后一轮双方幸存名单、单挑或合击判定及获胜球队。

`simulateTeamMatch(teamA, teamB)` 是唯一的单场比赛函数，小组赛和全部淘汰赛都调用它。阵亡只属于当前一场比赛；下一场开始时球队原始四人全部恢复。

## 玩家模式

每届世界杯完成抽签、组队和分组后，系统会从32支球队中随机分配1支作为“你的球队”，并自动进入“我的征程”。

- 主界面显示玩家球队4张卡、所在小组、个人战绩、当前阶段、下一场对手、积分简表和近期结果。
- 小组赛分为3个比赛日。玩家每轮亲自完成自己的比赛，随后电脑自动模拟该比赛日其余15场。
- 第一阶段逐场从尚未出战的4名武将中选将；电脑在回合开始、玩家选择之前秘密锁定自己的出场者，点击“确认出战”后双方同时揭晓。
- 尚未参加过本场战斗的电脑武将始终显示统一卡背，不显示姓名、武力、排名、品阶或战力；已揭晓武将可保留在战斗记录中。
- 第二阶段从幸存者中继续逐场选将；人数较多一方的多余武将自动轮空并明确记录，电脑继续使用同一AI策略。
- `selectAICombatant()` 只读取自己的合法可用武将、阶段、轮次和公开比分；65%概率采用保留王牌、落后追分或后程收官策略，35%概率随机出场，不读取玩家本回合选择。
- 双方都在第二阶段后存活时，最后一轮沿用普通战斗界面；1v1 直接单挑，多人合击在战场内展示加总和冲突动画，再揭晓比赛结果；一方全灭时仍立即结算。
- 对战过程包含当前比分、双方出战记录、卡牌选择状态、同时亮将、属性克制提示、队长播报、卡牌滑入、胜者高亮、败者灰化和回合切换。
- 弱者只触发15%加成但仍落败时显示“爆发 / 绝地反击”；只有加成后真正反超获胜才显示“爆冷 / 以弱胜强”。
- 晋级四强后显示球队、队长、当前战绩和半决赛对手；赛事结束按冠军、亚军、季军、第四名分别展示结算仪式、完整四人阵容与最终战绩。
- 玩家被淘汰后可以结束本届，也可以让电脑自动完成剩余比赛并查看最终领奖台。

## 战术卡（第一版）

每场玩家比赛开赛前，从随机出现的三张不同战术中选一张；下一场重新抽取。每张卡在本场最多成功发动一次，条件未满足则保留。现有六张卡为全军振奋（原始四将整场各 +2）、背水一战（幸存人数落后时本次单挑 +6）、侦察（随机揭示非本轮出场的存活敌将）、闪避（翻牌后本将将败且基础战力差不超过 5 时双方存活）、军心振奋（第三阶段团队总战力 +6）和奇兵突袭（单挑前声明，基础战力差不超过 5 时本次 +5）。所有加成都只存在于本场比赛，不改人物原始数据；战报记录携带战术、是否成功使用及事件。电脑对电脑比赛仍按原快速模拟。

## 背景音乐

项目不附带任何商业音乐或伪造音频。将有合法使用权的文件保存为 `assets/audio/bgm.mp3` 后，首次点击“开始世界杯”会尝试播放。BGM默认30%音量并循环，页头可以静音或调整0%—100%音量；页面切换不会重新开始。没有音乐文件时界面显示“音乐未安装”，游戏仍可正常运行。

## 自动测试

如果电脑已安装 Node.js，可以运行：

```powershell
node tournament_test.js
```

测试会使用固定随机种子完整模拟5届世界杯，并验证48场小组赛、每队3场、16队晋级、各轮场数、三阶段单场规则和前四名唯一性。

玩家模式测试：

```powershell
node player_mode_test.js
node tactics_test.js
```

该测试验证随机玩家球队、逐回合选将、AI提前锁定且不读玩家选择、重复出战保护、队长播报、退出重进、四强过场、分类颁奖、第二阶段轮空、最后一轮单挑与合击战力和完整赛事结束。

专项测试：

```powershell
node privacy_ai_audio_test.js
```

该测试验证确认前不泄露电脑武将、确认后才翻牌、AI不是固定顺序或纯随机、不读取玩家隐藏选择，以及BGM循环、静音、音量、页面切换连续性和缺少文件时的安全处理。

所有资源均为本地相对路径，可以直接部署到 GitHub Pages。
